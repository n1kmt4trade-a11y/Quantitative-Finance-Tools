# Quantitative Finance & Macro Intermarket Analyzer

A robust Python tool designed to perform cross-asset intermarket analysis, extract financial series, and generate visual performance reports. Built with a 100% resilient fallback structure to support automated quantitative workflows.

## Features
- **Data Scraping:** Automated fetching of historical adjusted closes via Yahoo Finance API (`SPY`, `TLT`, `GLD`).
- **Resilient Fallback:** Includes a pure-Python math fallback engine and synthetic data generator for offline/testing robustness.
- **Data Visualization:** Generates relative performance charts (Base 100) and cross-asset correlation matrices.
- **Interactive Outputs:** Creates standalone HTML dashboard reports powered by Chart.js.
